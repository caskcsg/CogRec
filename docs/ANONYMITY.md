# Anonymity Statement

This repository is prepared for anonymous review. It is intended to contain no author names, institutional paths, private emails, private datasets, access tokens, model checkpoints, training logs, or generated outputs.

The release focuses on the supervised CogRec reproduction path. Visualization utilities and preference-optimization/GRPO code are intentionally excluded from the anonymous package because they are not required to reproduce the main supervised pipeline.

Before publishing an anonymous GitHub repository, create a clean repository without prior commit history and run a final scan for local paths, credentials, generated data, checkpoints, and logs.
